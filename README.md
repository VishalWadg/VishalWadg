### TempMail — Disposable Email Service
> Instant throwaway inboxes — no signup, auto-expires in 30 minutes. Built to understand how email infrastructure actually works.

- **Real SMTP server** — SubEthaSMTP receives actual inbound email on port 2525, no third-party relay needed
- **Real-time inbox** — Redis Pub/Sub bridges to WebSocket/STOMP; new emails appear instantly without polling
- **Swappable SMTP layer** — `MailReceiverService` interface decouples the SMTP adapter from business logic; replacing SubEthaSMTP requires zero changes to the rest of the system
- **Auto-expiry by design** — Redis TTL silently wipes the entire inbox after 30 minutes

**Status:** Backend Complete — frontend in progress  
**Stack:** `Java` `Spring Boot` `SubEthaSMTP` `Redis` `WebSocket/STOMP` `Docker`  
[View Repository →](https://github.com/VishalWadg/Tempmail)
